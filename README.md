# NATINF Route — version 2
Application web progressive (PWA) installable sur iPhone. Choix de profil Gendarmerie / Police, recherche par catégories et favoris locaux. Gyrophare rouge et bleu fixe.

**Important :** les emblèmes GN/PN sont des monogrammes de remplacement, pas les logos officiels. Les intitulés d'infractions sont des aides de recherche ; aucun numéro NATINF ou barème n'est inventé. Une base juridique vérifiée doit être intégrée avant usage opérationnel.

Déploiement Netlify : publier le contenu de ce dossier à la racine du site. Aucun build nécessaire.
